# Night's Catch

One-page site for Night's Catch, a 4-star fisherman's cottage in Porthleven, Cornwall. Replicated from [nightscatch.co.uk](https://nightscatch.co.uk/).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).
